# RRR Manipulator Kinematics and Simscape Modeling

## Project Overview
This project focuses on the forward kinematics of a 3-DOF RRR robotic arm.

## Tasks Performed
*   Derived the Denavit-Hartenberg (DH) parameters and transformation matrices.
*   Calculated the end-effector position using MATLAB.
*   Modeled the physical robot in Simulink/Simscape Multibody using imported 3D CAD files.
*   Validated the analytical MATLAB solutions against the physics-based Simscape simulations.
